**<h2 align="center">📅 Calculadora com while utilizando os quatro operadores aritméticos</h2>**

> Projeto em Python.  

**<p align="center">** 
**Este simples projeto utiliza a estrutura de repetição como o while, para verificar a saída do usuário, podendo o mesmo colocar dois valores e os quatro operadores básicos da matemática. Uso também as funções de tratamento de erro, como TRY e EXCEPT, para verificar possíveis erros de um valor digitado incorretamente.**

**</p>** 

---

**🛠️ Foco do projeto:** 

**- Entender o funcionamento do while + try/except** 

**- Desenvolver a lógica de programação usando estruturas de repetição** 

**- Implementar tratamento de erros**
